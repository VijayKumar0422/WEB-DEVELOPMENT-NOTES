# 📚 My Developer Notebook

Welcome to my learning repository! 👋

## 🚀 Topics Covered

### 🌐 Frontend Development

- **HTML** — Structure of web pages
- **CSS & CSS3** — Styling, layouts, Flexbox, Grid, and animations
- **JavaScript** — Core concepts, DOM manipulation, and asynchronous programming
- **Bootstrap** — Responsive layouts and ready-to-use components
- **Tailwind CSS** — Utility-first CSS and responsive design
- **React.js** — Components, props, state, hooks, and routing
- **Next.js** — Modern React development and full-stack web concepts

### ⚙️ Backend Development

- **Node.js** — JavaScript runtime and server-side programming
- **Express.js** — Building servers, APIs, and backend applications
- **MongoDB** — NoSQL database concepts and CRUD operations

### 🗄️ Database & Query Language

- **SQL** — Queries, filtering, joins, grouping, and data manipulation
